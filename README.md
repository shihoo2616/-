# 이번 생은 축구다 — Football Life

브라우저에서 실행되는 축구 선수 커리어 시뮬레이션 게임입니다.

## 실행
`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하세요.

## 주요 시스템
- 선수 생성 / 포지션 / 주발 / 플레이 스타일 / 성장 배경
- 22개 세부 능력치와 포지션별 OVR
- 주간 훈련, 체력, 컨디션, 멘탈
- 경기 시뮬레이션과 경기 기록
- 감독 신뢰도와 선발 경쟁
- 계약 / 연봉 / 시장가치 / 이적
- 국가대표
- 시즌 종료 및 성장/노쇠화
- 커리어 기록 / 명예의 전당
- 랜덤 인생 이벤트
- localStorage 자동 저장

## 주의
특정 상용 게임의 소스 코드나 자산을 복제하지 않고 독자적으로 구현한 프로젝트입니다.
